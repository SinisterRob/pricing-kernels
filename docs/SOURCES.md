# Primary Actuarial Source Documents & Traceability

`pricing-kernels` implements published, peer-reviewed property & casualty commercial lines actuarial pricing, classification, experience rating, retrospective plans, credibility, severity layering, reinsurance, trending, and underwriting-risk capital methods directly from primary literature. Every kernel listed below is numerically verified in [`tests/source_benchmarks.rs`](../tests/source_benchmarks.rs).
